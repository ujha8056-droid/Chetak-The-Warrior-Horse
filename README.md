# Chetak - The Warrior Horse

An endless-runner style 3D game built with Vanilla JavaScript and Three.js. 
Ride as Maharana Pratap on Chetak through dynamically generated terrain, dodging obstacles and defeating enemies.

## Documentation
For new developers, please start by reading the [New Developer Guide](docs/development/NEW_DEVELOPER_GUIDE.md).

For architectural overview, see [Project Architecture](docs/architecture/PROJECT_ARCHITECTURE.md).

For contributing guidelines, see [Contributing](CONTRIBUTING.md).

## Getting Started
1. Clone the repository
2. Install dependencies: `npm install`
3. Run the development server: `npm run dev`
4. Open the localhost URL in your browser.
